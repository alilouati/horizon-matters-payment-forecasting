# Map of numerical comparisons to stored predictions and generated outputs (version v1.1.0)

Every comparison of accuracy stated in the manuscript is listed with the stored predictions it uses, the
aggregation rule and the generated file that supports it. All files are regenerated by
`python reproduce_results.py`.

Aggregation rules:

- **Single-run mean**: the error (sMAPE, %) of each training run is computed, then averaged over seeds
  (`*_mean`, `sMAPE_mean`, column "Mean" of Table 24).
- **Seed-averaged forecast**: the forecasts of all seeds are averaged per (origin, horizon) first, then the error is
  computed (`*_ens`, column "Avg." of Table 24). All DM tests and bootstrap intervals use seed-averaged forecasts.
- Classical baselines are deterministic: both rules give the same value.
- "Complete horizon" means the mean over h = 1..12 on the eight test origins with all twelve horizons observed.
  "h = 1" means the 19 rolling one-step test months.

Stored predictions: `runs/2022-12/` (main experiment, 20 seeds), `runs_tuned/`, `runs_tx/`, `runs_mv/`
(additional experiments), `runs_r3/<variant>/2022-12/` (normalization experiments, seeds 0–9), `runs_r3/*/20xx-12/`
(earlier cutoffs).
